Put scanned court orders and departmental letters here as PDFs.

Then open assets/data/schools.js and set the "file" value on the matching
DOCUMENTS entry to the filename, for example:

  file: 'wp-10372-2008.pdf'

That row will turn into a working download link on achievements.html.

Suggested naming: lowercase, hyphens, no spaces.
  wp-10372-2008.pdf
  supreme-court-order.pdf
  board-letter.pdf
